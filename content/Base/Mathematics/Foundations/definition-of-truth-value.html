真理値の定義についてを、日本語という自然言語の曖昧さを排除し、数学の基礎となる命題において真偽がうまく定まるように定義します。

ここでは、真理値と論理演算（ブール代数構造）を定義し、記号「$0$」「$1$」の割り当てと、集合論（フォン・ノイマン構成）へ接続します。

真理値の定義

数学の世界を作るための、一番最初の作業です。まだ「数字（$0$や$1$）」も「集合」も「数式」もこの世に存在しない状態からスタートします。
私たちが最初に行うのは、人間の素朴な直感（メタ言語のレベル）を使って、「互いに区別できる2つの何か（状態）」を用意することです。

一.2つの対象の導入
・名前は何でも構いませんが、ここでは仮に $\top$（トップ/真） と $\bot$（ボトム/偽） という2つの異なる記号（対象）を用意します。
・重要な約束事はたった一つ、「$\top$ と $\bot$ は別物である（$\top \neq \bot$）」ということだけです。

ニ.「真」と「偽」の定義
・私たちはこれから、さまざまな文（命題）を作りますが、すべての文は最終的にこの $\top$ か $\bot$ のどちらか一方だけ に対応づけられる、というルールを敷きます（二値原理）。
・ある文が $\top$ に対応することを「その文は真である」、$\bot$ に対応することを「その文は偽である」と定義します。

※この時点では、 $\top$ や $\bot$ に「$1$や$0$」という数値的な大きさも、「正しい・間違っている」という道徳的な意味もありません。ただ「$2$種類の区別できるラベル（スイッチのONとOFFのようなもの）」があるだけです。

論理演算の定義

$\top$（真） と $\bot$（偽） の2つの状態に対して、それらを「反転させたり」、「組み合わせたり」する操作（関数）を定義します。ここでもまだ数字の $0$ や $1$ は使いません。

最も基本的な2つの操作だけを定義します。

一.否定（$\neg$）：状態を反転させる操作
1つの状態を受け取り、もう一方の状態を返す操作です。
・$\neg \top = \bot$
・$\neg \bot = \top$

二.論理積（$\wedge$）：2つの状態を受け取り、両方が $\top$ の場合だけ $\top$ を返す操作
2つの状態を受け取り、「両方とも $\top$ のときだけ $\top$ を返し、それ以外はすべて $\bot$ を返す」という操作です。
・$\top \wedge \top = \top$
・$\top \wedge \bot = \bot$
・$\bot \wedge \top = \bot$
・$\bot \wedge \bot = \bot$
